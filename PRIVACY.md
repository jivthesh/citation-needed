# Privacy

citation-needed collects no data.

- The scanner reads source files on your machine, in the path you give it.
- The `SessionStart` hook reads one local rules file and adds it to your agent's context.
- The plugin makes no network requests, has no server, and stores nothing.

Your coding agent reads the code it audits, as it does for any task. That is covered by your agent provider's own terms.

`npx skills add` is a separate tool. It sends anonymous install counts to skills.sh.

Questions: open an issue at https://github.com/jivthesh/citation-needed/issues
